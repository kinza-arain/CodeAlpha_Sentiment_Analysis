# CodeAlpha Task 4 – Sentiment Analysis

##  Project Overview

This project is completed as part of the **CodeAlpha Data Analytics Internship – Task 4: Sentiment Analysis**.

The objective of this project is to analyze movie reviews and automatically classify them into **positive** or **negative** sentiments using Natural Language Processing (NLP) and Machine Learning techniques.

For this project, the **IMDB Dataset of 50K Movie Reviews** was used. The dataset contains 50,000 movie reviews with their corresponding sentiment labels.

---

##  Objective

The main objective of this project is to build a machine learning model that can predict the sentiment of a movie review based on its text.

The project focuses on:

- Text preprocessing
- Exploratory analysis of reviews
- Handling text data
- TF-IDF feature extraction
- Machine Learning classification
- Cross-validation
- Model comparison
- Model evaluation
- Sentiment prediction on new reviews
- Identifying important positive and negative words

---

##  Dataset

The project uses the **IMDB Dataset of 50K Movie Reviews**.

### Dataset Information

- Total reviews: **50,000**
- Positive reviews: **25,000**
- Negative reviews: **25,000**
- Features: **2**

### Columns

| Column                   | Description |

| `review`                 | Text of the movie review |
| `sentiment`              | Sentiment label: positive or negative |

The dataset is balanced, with an equal number of positive and negative reviews.
